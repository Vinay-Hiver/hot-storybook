# Tabs

The row of tabs that switches between views of the same content. It is the row only. Show the matching content yourself, using the selected value.

## Outlined

Underline tabs on a thin line. The selected tab is bold with a dark underline. Each tab can show a count in a **Badge**.

<Canvas of={TabsStories.Outlined} />

## Filled

A pill selector for two or three options. The selected tab is a white pill on a grey track. It is called "Filled" and "Type3" in the Figma file, which differ only in the number of tabs.

<Canvas of={TabsStories.Filled} />
