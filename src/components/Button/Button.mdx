# Button

The main action control. Use one **Primary** button per view for the main action, and Secondary, Filled or Ghost for the rest.

## Types

<Canvas of={ButtonStories.Types} />

- **Primary**: the main action on a page.
- **Secondary**: outlined, for supporting actions.
- **Filled**: soft grey fill, for low-emphasis actions.
- **Ghost**: no fill until hovered, for toolbars and dense areas.
- **Error**: destructive actions such as delete.
- **Neutral**: dark, for strong actions that aren't the brand action.

## Icons

Icons are 16px and sit before or after the label. An icon-only button is square and must have an `aria-label`.
