# Checkbox

Lets people turn one option on or off, or pick several options from a list. Use **Radio** when only one option can be chosen, and **Switch** for settings that take effect straight away.

## Selection

A checkbox can be unchecked, checked or indeterminate. Indeterminate shows that only some of a group's options are selected. Without a label, give the box an `aria-label`.

## States

Use `invalid` with a message elsewhere that says what to fix, and `required` to add the red asterisk.
