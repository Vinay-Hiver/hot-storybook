# Table

Shows rows of information in columns. It has a header row and one row per item. Rows are 64px tall and the header is 48px. A thin border runs around the table, with rounded 12px corners, and the table fills the width of its container.

## Basic

Give it `columns` and `rows`. A column can set a `width` as a percentage of the table (`'50%'`) or a fixed size (`'80px'`). Columns without a width share the space that is left equally. For example, a first column of `'50%'`, a second of `'10%'` and two columns with no width gives 50% / 10% / 20% / 20%. To put something other than text in a cell, such as a **Switch**, give the column a `render` function.

## Row actions

Give the table `rowActions` (1 to 4 icon buttons) and they appear at the right end of a row when it is hovered or has keyboard focus. Each action has an `icon`, a `label` (shown as a tooltip) and an `onClick`. Set `divided` on an action to set it apart with a thin line, as Delete is in Figma. The rows below are pinned to show 1, 2, 3 and 4 actions.
