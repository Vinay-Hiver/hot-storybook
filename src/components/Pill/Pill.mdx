# Pill

A small coloured label with a lightning bolt that shows where a time stands in a conversation. **FRT** is the first response time and **RT** is the resolution time. It is 18px tall.

## Statuses

Set `kind` (`frt` or `rt`) and `status`. The colour follows the status: grey for **upcoming**, orange for **due**, red for **overdue** and green for **done**. Screen readers read it as, for example, "First response time: overdue".
