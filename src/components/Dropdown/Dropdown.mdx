# Dropdown

The menu panel that opens under a field or button, for choosing from a list. It is the panel only. Place it under your trigger yourself, for example inside a popover. The panel is 260px wide and has an optional title, search box and Cancel and Apply buttons.

## Styles

Five row styles: checkboxes for choosing several options, an avatar with a status dot, a small icon, radios for choosing one, and plain text. The rows are built from **List item**.

<Canvas of={DropdownStories.Styles} />

## Search and buttons

Both are optional. Add search for long lists. Add Cancel and Apply when the choice should only be saved on confirmation, which suits the checkbox style.
