# Input

A single-line text field with an optional label, helper text, prefix, counter and action. For longer text, use **Textarea**.

## Sizes

Medium is 40px tall and is the default. Small is 32px tall, for dense forms and toolbars.

<Canvas of={InputStories.Sizes} />

## Prefix, counter and action

A prefix can be a 14px icon or a short string such as `https://`. The counter needs `maxLength`. The action sits on the right edge, divided from the text.

<Canvas of={InputStories.Affixes} />

## Tags

Add `tags` (or `defaultTags`) to turn the field into a tags input. Typing and pressing Enter or comma adds a **Chip / Tag**. Backspace on an empty box removes the last one, and each tag has its own remove button. In Input the tags stay on one line. In **Textarea** they wrap onto more lines.

<Canvas of={InputStories.Tags} />

## Phone

Add a `country` to show the country button before the number: a flag, the dial code and a chevron. The number box accepts only digits, spaces, hyphens and brackets, so letters and symbols are removed as they are typed or pasted. Only the United States is designed in Figma, so it is the only built-in country (`unitedStates`).

Give it a `countries` list and pressing the button opens the **country list**. It is built from the product code, not from Figma: a search box ("Search countries..."), then a row per country with its flag, name and dial code, a blue tick on the selected one, and "No results found" when nothing matches. Import the product's full list of 242 countries as `countries`. Picking a country closes the list, shows that country's flag and dial code on the button, and calls `onCountryChange`.
