# Menu

A small action menu that flies out from a button, for example the more button of a row. It is a white panel at least 200px wide, with a thin grey border, 8px rounded corners and a soft shadow. Each row is 32px tall with an optional 16px icon and a label; a row turns grey on hover.

Put it in a [Popover](?path=/story/components-popover--playground) to open it: use the `right-start` placement to open it beside the button.
