# Admin sidebar

The menu down the left of the admin panel. It is 240px wide and fills the height of its container. It has a heading, a first item on its own, then groups of items under small titles.

## Default

Give it `sections`. Each section has an optional `title` and a list of `items`, and each item has an `id`, a `label` and an `icon` from the HOT icon set. Set `value` to the `id` of the selected item and listen to `onChange` to switch pages. The selected item has a light blue background and blue text.
