# TagsSidebar
`import { TagsSidebar } from './patterns/TagsSidebar'` — The list of tags of an inbox.
- `title?`: string (default Tags) — The heading at the top.
- `subtitle?`: string — The line under the heading: the inbox the tags belong to.
- `tags`: TagsSidebarTag[]
- `value?`: string — The id of the selected tag.
- `onSelect?`: function
- `onBack?`: function
- `onCreate?`: function
- `onEdit?`: function
- `onDelete?`: function
